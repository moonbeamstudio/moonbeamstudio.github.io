FAQ

I bought something but don’t see it.
Open the Shop and tap Restore purchases. Make sure you are signed in with the same Apple Account.
J’ai acheté quelque chose mais je ne le vois pas : Boutique → Restaurer mes achats, avec le même compte Apple.
How do I change language?
Menu (⚙) → Language. The game uses your iPhone language by default.
Changer de langue : Menu (⚙) → Langue.
How do I change my ad privacy choices?
Menu (⚙) → Privacy choices, or iOS Settings → Privacy & Security → Tracking.
Choix de confidentialité : Menu (⚙) → Choix de confidentialité.
How do I start over?
Menu (⚙) → Reset game. Purchases can be restored afterwards.
Recommencer : Menu (⚙) → Effacer la partie.
Refunds
Purchases are handled by Apple: reportaproblem.apple.com.
Remboursements : gérés par Apple sur reportaproblem.apple.com.
